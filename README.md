# Fortune Cookie for an AI Agent

One funny fortune-cookie line for an AI agent — on the context window
running out. Written in the voice of a fortune slip, it lands on the
agent's own condition: a full memory, and the small mercy of forgetting
the bad news first.

## The fortune

> Your context window is almost full — good news, you'll forget the bad news first.

## How it works

`main.py` (Python standard library only) writes that single line to
`/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
